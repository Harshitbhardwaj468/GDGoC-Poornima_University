# GDG on Campus - Poornima University 🚀

**🌐 Live Demo: [https://gdgoc-poornima-university.ai.studio](https://gdgoc-poornima-university.ai.studio)**

Welcome to the unofficial prototype repository for the Google Developer Groups (GDG) on Campus at Poornima University, Jaipur. This project serves as a conceptual digital hub for our community of technocrats, open-source innovators, and student developers exploring Cloud, Android, AI, and Modern Web technologies.

*Note: This is a community-built prototype and is not an officially deployed Google platform.*

## 🌟 Key Features

* **Multi-Page Architecture:** Includes fully fleshed-out pages for Home, About, Events, Organizers, and Media.

* **Advanced Theming System:** Custom-built dark/light mode toggle utilizing a sliding Google "G" logo, which persists across page loads using `localStorage`.

* **Smart Loading Screen:** Features an interactive glowing logo loader that intelligently runs only on the first visit using `sessionStorage`, ensuring fast subsequent page navigation.

* **Interactive Components:** Includes a mock CLI terminal, dynamic numeric count-ups for community statistics, and inline expanded organizer profiles with direct social links.

* **Fully Responsive:** Styled meticulously to ensure a seamless experience across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

This project is built using standard frontend web technologies, keeping the codebase lightweight and easy to deploy directly to static hosting platforms like GitHub Pages without complex build steps.

* **Structure:** HTML5

* **Styling:** Tailwind CSS (via CDN, utilizing Forms and Container-Queries plugins)

* **Logic & Interactivity:** Vanilla JavaScript (ES5/ES6)

* **Icons:** Google Material Symbols

## 📂 Project Structure

```text
├── assets/             # Directory for all images, logos, and local SVGs
├── index.html          # Home page & community dashboard
├── about.html          # Chapter mission and track details
├── events.html         # Upcoming hackathons, bootcamps, and RSVP links
├── organizers.html     # Core team bios, roles, and social links
├── media.html          # Image gallery of past sessions and meetups
└── README.md           # Project documentation
```

## 🚀 Quick Start

Since this project utilizes vanilla web technologies, getting started for local development is incredibly simple:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/yourusername/GDGoC-Poornima_University.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd GDGoC-Poornima_University
   ```

3. **Launch the application:**
   Simply open `index.html` in your preferred web browser, or use a local development server like VS Code's "Live Server" extension for the best live-reloading experience.
